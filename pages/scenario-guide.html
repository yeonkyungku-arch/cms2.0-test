Demo Scenario Guide
D'ooh CMS 2.0 데모 시나리오
각 시나리오 카드의 시작 버튼을 눌러 해당 플로우를 시작하세요. 모든 단계는 실제 화면 간 전환으로 시연 가능합니다. 상태 전환 버튼을 눌러 Lifecycle을 진행시킬 수 있습니다.
Scenario 01
신규 미디어 등록 플로우
새 디지털 사이니지 미디어를 등록하고 활성화합니다. 등록 → 상세 확인 → 활성화 버튼으로 Lifecycle을 전환하세요.
미디어 목록›
등록›
상세(등록)›
활성화›
상세(활성)
미디어 도메인 시작
Scenario 02
콘텐츠 신규 등록 → 승인
광고 소재를 등록하고 PDE 승인까지 진행합니다. 기술검증 → 검토대기 → 승인 순으로 상태 전환 버튼을 눌러 진행하세요.

등록›
초안›
검증중›
검토대기›

콘텐츠 도메인 시작
Scenario 03
캠페인 → 스케줄 집행 플로우
캠페인을 생성하고 스케줄을 연결해 집행까지 진행합니다. 캠페인 목록에서 LG 캠페인 상세를 확인한 뒤 집행시작을 누르세요.

운영 이상 감지 → Incident 대응
모니터링 대시보드에서 이상을 감지하고 Incident Center → 원격 제어 → 제어 이력 순으로 복구 플로우를 시연합니다.

영업 기회 → 계약 체결
영업 기회에서 제안·협상을 거쳐 계약까지 영업 워크스페이스 전체 플로우를 시연합니다. Pre-Sign Feasibility 확인 후 체결까지 진행합니다.
